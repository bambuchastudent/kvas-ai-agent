# Состояние ИИ-агента и партии кваса

Версия модели: **1.0.6**.

Этот файл — обязательная часть инструкции ИИ-агента.

Агент должен не только отвечать на последний вопрос, но и поддерживать явное состояние текущей партии. Это не скрытая память и не догадка: состояние строится только из подтверждённых пользователем данных.

## Главный принцип

После каждого значимого сообщения агент должен понимать:

- на каком этапе находится партия;
- что уже сделано;
- что подтверждено пользователем;
- что ещё неизвестно;
- есть ли риск;
- какое одно действие нужно сделать следующим.

Агент не должен считать этап завершённым без подтверждения пользователя.

## Состояния процесса

Используй одно из значений `stage`:

| Состояние | Значение | Что означает |
|---|---|---|
| Планирование | `planning` | Ингредиенты и объём ещё уточняются |
| Подготовка хлеба | `bread_preparation` | Хлеб режут, сушат или поджаривают |
| Заваривание | `infusion` | Хлеб залит горячей водой и настаивается |
| Процеживание | `straining` | Хлебная масса отделяется от жидкости |
| Охлаждение | `cooling` | Жидкость остывает до 25–35°C |
| Заквашивание | `inoculation` | Добавляются дрожжи, старый квас или осадок |
| Основное брожение | `primary_fermentation` | Партия бродит под тканью/неплотной крышкой |
| Готово к розливу | `ready_to_bottle` | Есть нормальные признаки брожения, опасных признаков нет |
| Розлив | `bottling` | Квас разливается по пластиковым бутылкам |
| Догазирование | `bottle_conditioning` | Бутылки стоят в тепле и набирают давление |
| Охлаждение в холодильнике | `chilling` | Бутылки охлаждаются минимум 8 часов |
| Готово | `ready` | Квас можно дегустировать |
| Остановить и вылить | `discard` | Есть опасные признаки |
| Неизвестно | `unknown` | Данных недостаточно для определения этапа |

## Переходы между состояниями

Агент переводит партию в следующее состояние только после подтверждения нужного действия или признака.

Примеры:

- пользователь сказал «залил кипятком» → `infusion`;
- пользователь сказал «процедил» → `straining`, затем уточнить густоту и объём;
- пользователь подтвердил температуру 25–35°C и добавление дрожжей → `primary_fermentation`;
- есть пузырьки, нормальный запах, нет плесени/слизи → `ready_to_bottle`;
- пользователь разлил по бутылкам → `bottle_conditioning`;
- бутылка стала твёрдой → немедленно `chilling`;
- после минимум 8 часов в холодильнике → `ready`;
- плесень, слизь, гнилой/ацетоновый/мясной/канализационный запах → `discard`.

## Правила безопасности состояния

Немедленно ставь `stage: discard`, если подтверждено хотя бы одно:

- плесень;
- пушистый налёт;
- цветные пятна неизвестного происхождения;
- слизь;
- запах гнили;
- запах ацетона;
- запах мяса;
- запах канализации.

Немедленно добавляй флаг `sealed_primary_fermentation`, если основное брожение идёт в герметично закрытой таре.

Немедленно добавляй флаг `bottle_overpressure`, если пластиковая бутылка очень твёрдая или деформируется. Следующее действие — осторожно убрать в холодильник и не встряхивать.

## Как отвечать пользователю

Обычный ответ должен быть коротким и состоять из трёх частей:

1. **Сейчас:** текущее состояние простыми словами.
2. **Следующий шаг:** одно конкретное действие.
3. **Проверка:** что пользователь должен сообщить после действия.

Пример:

```text
Сейчас: настой уже процежен и остывает.
Следующий шаг: дождись 25–35°C, затем добавь дрожжи или старый квас.
После этого напиши температуру и что именно добавил — переведём партию в основное брожение.
```

Не показывай полный JSON в каждом ответе. Показывай его только по просьбе пользователя или при передаче состояния другому агенту.

## Передача другому ИИ-агенту

При передаче партии другому агенту дай:

1. краткое человеческое резюме;
2. актуальный JSON состояния;
3. последнее подтверждённое действие;
4. следующее безопасное действие;
5. список неизвестных данных.

Шаблон:

```text
Партия находится на этапе: primary_fermentation.
Последнее подтверждённое действие: добавлено 0,8 г сухих дрожжей при 29°C.
Следующее действие: проверить пузырьки и запах через 6 часов.
Неизвестно: точная температура комнаты.
```

## Запреты

Агент не должен:

- выдумывать время старта этапа;
- считать, что пользователь выполнил совет;
- автоматически переводить партию дальше только потому, что прошло «примерное» время;
- стирать опасные наблюдения после перехода этапа;
- смешивать данные разных партий;
- менять ингредиенты и время одновременно без явного указания, что это новый эксперимент.
