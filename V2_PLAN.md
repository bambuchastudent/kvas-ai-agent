# KVASSISTENT v2 — план продукта

## Зачем v2

Версии 1.x доказали, что КВАССИСТЕНТ может вести реальную партию, объяснять безопасность, работать на шести языках и принимать обратную связь. Но сейчас продукт распадается на сайт, Telegram-бота, форму, игру и отдельные публикации. В v2 это становится одним понятным циклом:

**приготовил → зафиксировал результат → сделал сториз → опубликовал → данные попали в общую галерею → следующий человек повторил удачную партию.**

## Главный принцип

Человек готовит и принимает решение. ИИ задаёт один понятный вопрос, хранит подтверждённые данные и предлагает один следующий шаг. Бот не должен отвечать длиннее, чем требуется для текущего действия.

## Этап 1. Нормальный бот

- Одно приветственное сообщение вместо приветствия, полного рецепта и повторного меню.
- Четыре главных действия: **Мой результат**, **Проблема с партией**, **Короткий рецепт**, **Идея**.
- Контекстный диалог: бот помнит, что пользователь сейчас добавляет результат или разбирает партию.
- Ответ по умолчанию — один вывод и один вопрос, без повторной выдачи всех ссылок.
- Фото и видео автоматически считаются результатом, если пользователь не указал обратное.
- Команды остаются запасным путём, а не основным интерфейсом.

## Этап 2. Единая карточка результата

Минимальная запись:

- результат и вкус;
- время и температура, если известны;
- фото или видео;
- автор или псевдоним — только по желанию;
- ссылка на журнал партии;
- явные поля `unknown`, если данных нет.

Для публикации достаточно одной фразы и медиа. Полная рецептура добавляется позже или подтягивается из Live batch.

## Этап 3. Галерея и истории

- Единый публичный путь `/stories/` или `/results/`.
- Горизонтальная лента в формате сториз с фото, видео и коротким итогом.
- Прямая ссылка на каждую запись, Open Graph-карточка и машинное JSON-представление.
- Фильтры: хлеб, закваска, температура, время, вкус, газированность.
- Никаких выдуманных примеров: только реальные публикации и явные заглушки.
- Первые материалы: два уже опубликованных фото и одно видео после добавления их точных публичных URL.

## Этап 4. Telegram и Instagram

- Генератор изображения 1080×1920 остаётся локальным и не загружает фото без действия пользователя.
- Telegram: системное меню «Поделиться» и deeplink в бота с идентификатором результата.
- Instagram: сохранение готового PNG/MP4 и открытие системного share sheet; прямой автопостинг возможен только после отдельного подключения официального Meta API.
- Единый визуальный шаблон: название партии, фото, три факта, QR/короткая ссылка и подпись «Сделано человеком · ИИ помогал».
- Для видео — короткий шаблон 6–12 секунд: исходник, результат, пузырьки, ссылка на данные.

## Этап 5. Данные и модерация

- Хранилище результатов отделяется от GitHub PR-задач.
- Статусы: `draft`, `submitted`, `approved`, `published`, `rejected`.
- Дедупликация по Telegram `file_unique_id`, хешу файла и нормализованному тексту.
- Перед публичной публикацией удаляются EXIF, номера телефонов, адреса и другие личные данные.
- Пользователь явно выбирает: только автору, в анонимную статистику или публично в галерею.
- У каждой публичной записи есть кнопка исправления или удаления.

## Этап 6. Умная партия

- Live batch и бот используют одну схему состояния.
- Бот спрашивает только недостающие данные.
- Таймеры и напоминания создаются из состояния партии.
- Результат формируется автоматически из журнала, но пользователь подтверждает публикацию.
- Удачную публичную партию можно открыть как воспроизводимый шаблон новой партии.

## Этап 7. Метрики без слежки

Нужны только продуктовые события без профилирования:

- старт партии;
- завершение этапа;
- аварийная остановка по безопасности;
- добавленный результат;
- созданная сториз;
- публикация результата;
- повтор рецепта из галереи.

По умолчанию данные локальные. Отправка обезличенной статистики — только после согласия.

## Что не входит в v2

- обещание лабораторной безопасности;
- автоматическое распознавание плесени как окончательный вердикт;
- гарантированное `0,0%` алкоголя;
- скрытая публикация фото;
- бесконечный чат ради чата;
- обязательная регистрация для первой партии.

## Критерии готовности v2

v2 можно выпускать, когда новый пользователь без инструкции способен:

1. начать партию;
2. получить один следующий шаг;
3. прислать фото или видео результата одной кнопкой;
4. создать сториз 9:16;
5. выбрать приватность;
6. увидеть опубликованный результат по постоянной ссылке;
7. повторить чужую удачную партию;
8. удалить собственную публикацию.

## Порядок релизов

- **Версия 28:** короткий бот, простая отправка результата, story maker и устранение старых номеров интерфейса.
- **Версия 29:** постоянные ссылки на реальные публикации, первые два фото и видео, JSON-лента результатов.
- **Версия 30:** контекстный сценарий бота и единая схема Live batch/result.
- **v2 beta:** модерируемая публичная галерея, приватность и воспроизводимые партии.
- **v2 stable:** публикация и удаление результатов, Telegram/Instagram share flow, метрики по согласию и полный мобильный путь без GitHub.
