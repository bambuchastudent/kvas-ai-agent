# kvas-ai-agent

Практическая база знаний и инструкция для ИИ-агентов по домашнему квасу без готовой закваски.

Контекст проекта: бытовой квас в Испании, когда под рукой есть засохший белый хлеб, немного сахара, изюм или финики, иногда старый квасной отжим из холодильника. Цель — получить безопасную, понятную и воспроизводимую инструкцию, которую можно дать другому ИИ-агенту или человеку.

## Быстрый старт

Основной сценарий на 3 литра:

1. Поджарить 300–400 г белого хлеба до тёмно-золотистого цвета.
2. Залить 3 л кипятка или 2,5 л кипятка, если есть 500 мл старого отжима.
3. Настоять 4–8 часов.
4. Процедить.
5. Добавить 100–150 г сахара.
6. Остудить до 25–35°C.
7. Добавить дрожжи для первой партии или старый отжим для следующих партий.
8. Оставить на 8–12 часов при комнатной температуре.
9. Разлить по пластиковым бутылкам.
10. Добавить немного изюма или сахара для газа.
11. Держать в тепле 2–6 часов, затем убрать в холодильник.

## Главное правило безопасности

Квас не должен пахнуть гнилью, тухлым, ацетоном, мясом или канализацией. Не должно быть пушистой плесени, цветных пятен или слизи. Если есть такие признаки — вылить.

## Для ИИ-агентов

Главный файл для передачи другому агенту: [`agent-instructions/kvas-agent.md`](agent-instructions/kvas-agent.md).

Агент должен вести пользователя пошагово, проверять температуру, запах, наличие плесени, давление в бутылках и не советовать держать закрытые бутылки долго в тепле.
