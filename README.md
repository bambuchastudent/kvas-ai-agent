## Что изменилось в 1.1.1.1.1.1.1.1

Появилась **«Живая партия»** — мобильный бытовой помощник, который превращает наблюдения за банкой в один ясный следующий шаг:

1. заводит партию с объёмом, сахаром, временем старта и температурой жидкости;
2. запоминает check-in по поверхности, запаху, вкусу, солнцу и крышке;
3. немедленно останавливает бытовой протокол при плесени, слизи, плохом запахе или 35°C+;
4. показывает персональное время следующей проверки и понятный маршрут партии;
5. даёт короткий рецепт на 3 л прямо перед запуском сопровождения;
6. работает офлайн, без аккаунта, хранит историю локально и отдаёт ИИ-агенту структурированный JSON с `unknowns` и `safety_flags`;
7. объясняет каждый verdict через **AI safety brief**: температура, поверхность, запах, крышка, солнце и время показаны как проверяемые сигналы;
8. поддерживает русский, английский, испанский, немецкий и упрощённый китайский интерфейс.

Для короткого демо есть готовая реальная ситуация: **26 часов, 28°C, прямое солнце**.

## Главный вывод по жаре

Версия сохраняет исследование реальной ситуации: **28°C, банка стояла на солнце, основное брожение прикрыто тканью**.

> **28°C в тени — быстрый рабочий режим. Банку с прямого солнца нужно убрать.**

- измерять температуру жидкости, а не только воздуха;
- при 28°C проверять квас раньше и чаще;
- основное брожение не закупоривать герметично;
- длительное тёплое брожение требует контроля запаха, поверхности и вкуса;
- две недели в тепле — уже не базовый быстрый квас.

Полное исследование: [`docs/research-fermentation-heat.md`](docs/research-fermentation-heat.md).

## Что делать с банкой

1. Убрать с прямого солнца.
2. Оставить в тени или помещении.
3. Прикрыть чистой тканью, марлей или неплотной крышкой.
4. Измерить температуру жидкости.
5. Проверить пузырьки, запах, вкус, отсутствие плесени и слизи.
6. При нормальном результате процедить и перейти к розливу или охлаждению.

## Температурные границы

| Жидкость | Режим |
|---:|---|
| ниже 18°C | медленно |
| 18–24°C | рекомендуемый |
| 25–27°C | быстро, проверять раньше |
| 28–30°C | жарко, только тень и частая проверка |
| 31–34°C | переставить в прохладу |
| 35°C и выше | охладить и остановить бытовой протокол |

## Для людей и для ИИ

### Для людей

На главной странице сначала показаны короткий рецепт, визуальный комикс, жара, солнце, запах, проверка поверхности и безопасность.

### Для ИИ-агентов

Состояние включает:

- температуру воздуха и жидкости;
- максимальную температуру;
- прямое солнце и время на солнце;
- `temperature_zone`;
- вкус;
- флаги `direct_sunlight`, `hot_fermentation`, `overheated_fermentation`, `extended_warm_fermentation`.

Schema: [`agent-instructions/state.schema.json`](agent-instructions/state.schema.json).

## Как Codex помог в этой версии

Во время OpenAI Build Week **Codex на GPT-5.6** использовался как инженерный напарник: исследовал связи репозитория через Graphify, проверил существующие правила безопасности, реализовал устанавливаемую «Живую партию», добавил корневой агентский вход, рецепт первой партии, explainable **AI safety brief**, структурированный handoff и расширил rule-engine тесты.

До Build Week проект был многоязычной базой знаний. Версия `1.1.1.1.1.1.1.1` превратила её в работающий agent-native продукт: локальную PWA, которую судья может открыть без аккаунта, сборки или API-ключа. Датированная история коммитов, этот раздел, [release notes](release/RELEASE-1.1.1.1.1.1.1.1.md) и Codex `/feedback` session фиксируют границу новой работы.

Ключевые продуктовые решения остались человеческими: вести только одну подтверждённую партию, показывать наблюдения и неизвестные отдельно и никогда не выдавать бытовую оценку за лабораторный диагноз.
