# КВАССИСТЕНТ 1.1.1.1.1.1.1.1

Единиц в версии: **8**.

## Изменения

- Добавлена **«Живая партия»** — устанавливаемая мобильная PWA для регулярных check-in домашнего кваса.
- Температура, солнце, крышка, поверхность, запах и вкус превращаются в один персональный следующий шаг.
- Новый **AI safety brief** объясняет verdict шестью сигналами и явно перечисляет неизвестные.
- В корне появился `AI_AGENT_START.md`: единый старт для любого ИИ-агента, который читает репозиторий.
- Плесень, слизь, плохой запах, 35°C+ и герметичное основное брожение обрабатываются отдельными safety-ветками.
- Появились локальная история, время следующей проверки и прогресс партии.
- Перед запуском сопровождения появилась краткая пошаговая инструкция первой партии на 3 л.
- Данные остаются в браузере; аккаунт и облако не нужны. Состояние можно экспортировать как JSON или передать ИИ через Web Share.
- Интерфейс доступен на русском, английском, испанском, немецком и упрощённом китайском.
- Для демонстрации добавлен сценарий `companion/?demo=1`: 26 часов, 28°C и прямое солнце.
- Rule engine покрыт автоматическими проверками и встроен в CI перед полной публикацией.
