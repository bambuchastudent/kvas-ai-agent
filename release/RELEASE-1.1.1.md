# КВАССИСТЕНТ 1.1.1

**Единиц в версии: 3.**

Предыдущая версия: `1.1.0`.  
Следующая версия по правилу проекта: `1.1.1.1 · единиц: 4`.

## Главное изменение

Главная страница теперь начинает не с выбора формата, а с коротких лучших инструкций для человека.

После быстрого рецепта информация разделена на две независимые части:

1. **Для людей** — рецепт, последовательность действий, визуальный контроль и безопасность.
2. **Для ИИ-агентов** — состояние партии, `null` для неизвестных данных, следующий шаг, safety flags и передача контекста.

## Брендинг

Название продукта во всём главном интерфейсе пишется капсом:

```text
КВАССИСТЕНТ
```

Бренд напитка остаётся:

```text
Жижа
```

## Главная страница

Порядок блоков:

1. hero `КВАССИСТЕНТ`;
2. **Лучшие инструкции для людей**;
3. **Для людей** с пятью языками и PDF summary;
4. **Для ИИ-агентов** с пятью языками и PDF instructions;
5. галерея успешных напитков.

## Версии

Каноническая версия хранится в:

```text
release/version.json
```

Новая схема:

```text
1.1.1       · единиц: 3
1.1.1.1     · единиц: 4
1.1.1.1.1   · единиц: 5
```

Каждый следующий релиз добавляет сегмент `.1`. Счётчик показывает количество сегментов версии, равных единице.

Для подготовки следующего релиза:

```bash
python scripts/next-ones-version.py
```

## Публикация

Релиз содержит:

- 10 PDF;
- 10 соответствующих веб-страниц;
- summary для людей на пяти языках;
- instructions для ИИ-агентов на пяти языках;
- manifest с версией и `ones_count`;
- архив публикации;
- архив полностью собранного сайта.

Главная страница:

```text
https://kvassistent.pages.dev/v1.1.1/
```

## Pipeline

`.github/workflows/publish.yml` читает версию из `release/version.json` и проверяет:

- заголовок `<h1>КВАССИСТЕНТ</h1>`;
- блок **Лучшие инструкции для людей**;
- отдельные `for-people` и `for-ai-agents`;
- счётчик `единиц: 3`;
- 10 PDF и 10 веб-страниц;
- публикацию GitHub Release;
- развёртывание Cloudflare Pages.
