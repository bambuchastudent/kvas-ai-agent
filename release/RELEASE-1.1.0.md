# Квас 1.1.0 — Квассистент с пузырьками и галереей

Бренд: **Жижа**.

## Что изменилось

- Главная страница получила золотистый фон с поднимающимися пузырьками в стиле живого кваса или пива.
- Анимация реализована на CSS без тяжёлого GIF и отключается при системной настройке уменьшения движения.
- Внизу главной страницы появилась галерея успешных напитков сообщества.
- Галерея принимает только реальные фотографии и проверенные заметки — выдуманных примеров нет.
- Добавлена кнопка для отправки своей партии и инструкция по оформлению результата.
- Cloudflare Pages остаётся основным публичным сайтом и автоматически проверяется после обновления `gh-pages`.

## Публичный сайт

```text
https://kvassistent.pages.dev/v1.1.0/
```

Галерея:

```text
https://kvassistent.pages.dev/v1.1.0/#gallery
```

## Материалы релиза

- 10 PDF: summary и инструкция на пяти языках;
- 10 соответствующих веб-страниц;
- архивы публикации и полностью собранного сайта;
- machine-readable manifest;
- `gallery/drinks.json` и руководство `gallery/README.md`.

## Публикация

Workflow собирает и проверяет материалы, обновляет тег `v1.1.0`, создаёт GitHub Release, публикует ветку `gh-pages`, ждёт автоматический deployment Cloudflare Pages и проверяет наличие нового фона и галереи на публичной главной странице.
