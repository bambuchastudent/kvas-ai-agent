# КВАССИСТЕНТ 1.1.1.1.1.1

**Единиц в версии: 6.**  
Следующая версия: `1.1.1.1.1.1.1`.

## Главное изменение

В релиз добавлена схематическая картинка в стиле простого комикса, созданная по реальной фотогалерее партии.

Комикс показывает:

1. подготовку сухарей;
2. загрузку в ёмкость;
3. замачивание;
4. перелив в бутыль;
5. открытое первичное брожение под тканью без прямого солнца;
6. проверку примерно через сутки при 28°C и переход к процеживанию и охлаждению.

Файл: `share/kvassistent-1.1.1.1.1.1-comic.svg`.

На опубликованной странице комикс находится в отдельном разделе `#comic-guide` и также доступен как самостоятельный SVG-файл.

## Что сохранено из предыдущего исследования

- 28°C в тени считается быстрым рабочим режимом;
- прямое солнце исключено;
- температура жидкости важнее температуры воздуха;
- первичное брожение не закрывается герметично;
- оценка алкоголя не выводится только из времени и жары;
- для 3 л 100–120 г добавленного сахара дают теоретический максимум примерно 2,2–2,6% об. только из этого сахара;
- для теоретических 8% требуется около 370 г ферментируемого сахара, а на практике больше.
