# Квас 1.0.1

Бренд: **Жижа**.

## Что это

Первый оформленный публичный релиз проекта «Квас»: открытой базы знаний про домашний квас, бытовую ферментацию, безопасность, рецепты и инструкции для ИИ-агентов.

Главный фокус релиза: **воспроизводимый квас**. Не просто «примерный рецепт», а протокол, который можно повторять, сравнивать партия к партии и улучшать по журналу.

## Что входит

- README с описанием проекта и сообщением для шаринга;
- воспроизводимый протокол кваса;
- шаблон журнала партии;
- рецепты домашнего кваса;
- вариант на белом хлебе;
- варианты с изюмом и финиками;
- заметки про солод, ржаную муку и ржаной компонент;
- чеклист безопасности ферментации;
- анонимизированные советы сообщества;
- инструкции для ИИ-агентов на русском, английском, испанском и немецком;
- манифест проекта;
- гайд по участию;
- гайд по брендингу.

## Главные файлы релиза

- `README.md` — входная точка проекта;
- `recipes/kvas-reproducible.md` — воспроизводимый протокол;

## Baseline 1.0.1

На 3 л:

- вода — 3000 г или 2500 г + 500 г старого отжима;
- сухой белый хлеб — 300 г;
- Бородинский/ржаной хлеб или ржаные сухари — 100 г;
- сахар — 120 г;
- сухой солод — 30 г, если есть;
- или ржаная мука — 20 г, если нет солода;
- свежие дрожжи — 3 г только для первой партии;
- или сухие дрожжи — 0,8–1 г только для первой партии.

## Как собрать пакет локально

```bash
npm run package
```

или напрямую:

```bash
bash scripts/build-package.sh
```

После сборки появятся:

```text
dist/kvas-1.0.1.zip
dist/kvas-1.0.1.tar.gz
```

## Как собрать пакет через GitHub Actions

1. Открыть вкладку **Actions**.
2. Выбрать workflow **Build package**.
3. Нажать **Run workflow**.
4. Скачать artifacts:
   - `kvas-1.0.1-zip`
   - `kvas-1.0.1-tar-gz`

## Как сделать GitHub Release вручную

Через GitHub UI:

1. Открыть **Releases**.
2. Нажать **Draft a new release**.
3. Tag: `v1.0.1`.
4. Title: `Квас 1.0.1 — reproducible baseline`.
5. Вставить текст из этого файла.
6. Прикрепить архивы `kvas-1.0.1.zip` и `kvas-1.0.1.tar.gz`, если они собраны локально или скачаны из Actions.

## Принцип воспроизводимости

Менять только один параметр за раз:

- или хлеб;
- или сахар;
- или солод;
- или температуру;
- или время брожения;
- или закваску.

Иначе невозможно понять, почему следующая партия стала лучше или хуже.
