# Квас 1.0.2

Бренд: **Жижа**.

## Что это

Патч-релиз для воспроизводимого домашнего кваса. Главная правка: исправлен слишком тяжёлый baseline по сухарям.

В 1.0.1 было указано 400 г сухого хлеба на 3 л. Для полностью сухих сухарей это слишком много. В 1.0.2 норма разделена:

- полностью сухие сухари / сухой хлеб — 180–220 г на 3 л;
- оптимально — 150 г белых сухарей + 50–70 г ржаных / Бородинских;
- если хлеб не сухой, а просто подсохший — 250–300 г.

## Почему изменили

400 г настоящих сухарей дают слишком много сухого вещества на 3 л. Такой настой может стать слишком плотным, тяжёлым и хлебным, хуже процеживаться и хуже повторяться.

Для воспроизводимого питьевого кваса лучше держать baseline легче и понятнее, а насыщенность повышать отдельно: солодом, ржаным компонентом, временем настоя или следующей партией на старом отжиме.

## Сахар и сравнение с пивом

Добавлено пояснение: хлеб содержит углеводы, но в основном это крахмал. Дрожжи не превращают крахмал хлеба в сахар сами по себе.

В пиве работает солод и затирание: ферменты солода превращают крахмал зерна в сахара. В простом домашнем квасе полноценного затирания нет, поэтому сахар нужен для стабильного брожения, газа и повторяемого вкуса.

## Baseline 1.0.2 на 3 л

- вода — 3000 г;
- сухари / полностью сухой хлеб — 180–220 г;
- оптимально: белые сухари — 150 г + ржаные/Бородинские сухари — 50–70 г;
- если хлеб не сухой, а просто подсохший — 250–300 г;
- сахар — 100–120 г;
- сухой солод — 20–30 г, если есть;
- или ржаная мука — 10–20 г, если нет солода;
- свежие дрожжи — 2–3 г только для первой партии;
- или сухие дрожжи — 0,5–1 г только для первой партии;
- для следующих партий — 500 мл старого кваса/отжима или 3–5 ст. л. осадка.


```bash

```

```text

```

1. Открыть **Releases**.
2. Нажать **Draft a new release**.
3. Tag: `v1.0.2`.
4. Title: `Квас 1.0.2 — corrected dry bread baseline`.
5. Вставить текст из этого файла.
6. Прикрепить архивы `kvas-1.0.2.zip` и `kvas-1.0.2.tar.gz`, если они собраны локально или скачаны из Actions.

## Принцип воспроизводимости

Менять только один параметр за раз:

- хлеб;
- сахар;
- солод;
- температуру;
- время брожения;
- закваску.

Иначе невозможно понять, почему следующая партия стала лучше или хуже.
