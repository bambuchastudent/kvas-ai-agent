# КВАССИСТЕНТ 1.1.1.1.1.1.1

Единиц в версии: **7**.

## Изменения

- Graphify подключён к Codex и Git hooks: локальная карта знаний обновляется после изменений кода.
- Serena 1.6.0 подключена как MCP-сервер Codex с проектной конфигурацией Python и Bash.
- Добавлен `AGENTS.md`, который разделяет роли инструментов: Graphify отвечает за связи во всём репозитории, Serena — за символы и рефакторинг кода.
- Добавлены команды `npm run ai:setup`, `npm run ai:check`, `npm run graph:update` и `npm run graph:query`.
- Скрипт следующей версии теперь автоматически переносит версионированный SVG-комикс и обновляет ссылку в manifest.
- Сохранены исследование жары и солнца, расчёт границ алкоголя и визуальная инструкция версии 6.
