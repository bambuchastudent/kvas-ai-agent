# Версии КВАССИСТЕНТА

Базовая точка новой линии: **1.1.0**.

Текущий релиз: **1.1.1.1.1.1 · единиц: 6**.  
Следующий: **1.1.1.1.1.1.1 · единиц: 7**.

## Правило

После `1.1.1` каждый релиз получает ещё один сегмент `.1`:

```text
1.1.1           · единиц: 3
1.1.1.1         · единиц: 4
1.1.1.1.1       · единиц: 5
1.1.1.1.1.1     · единиц: 6
1.1.1.1.1.1.1   · единиц: 7
```

`ones_count` — количество сегментов версии, равных `1`.

Канонические данные: `release/version.json`.

Команда следующего релиза:

```bash
npm run next-release
```

Git tag повторяет точную строку версии: `v1.1.1.1.1.1`.
