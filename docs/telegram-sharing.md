# Как делиться проектом в Telegram

## Правильная ссылка

Для Telegram отправляй специальную страницу:

```text
https://bambuchastudent.github.io/kvas-ai-agent/v1.0.5/
```

У страницы зафиксированы:

- заголовок: **Квас Жижа для ИИ-агента**;
- изображение с бутылкой кваса;
- описание версии 1.0.5;
- кнопка «Поделиться в Telegram»;
- кнопка перехода в GitHub;
- ссылка на русскую инструкцию;
- ссылка на модель состояния партии.

## Готовое сообщение

```text
Квас Жижа для ИИ-агента

Открытая база знаний про воспроизводимый домашний квас: простой рецепт в граммах, безопасность, состояние текущей партии, журнал и инструкции для ИИ-агентов на русском, английском, испанском и немецком.

https://bambuchastudent.github.io/kvas-ai-agent/v1.0.5/
```

## Почему используется отдельная страница

Обычная ссылка на GitHub-репозиторий получает карточку, которую формирует GitHub. README не может надёжно управлять заголовком и изображением Telegram-превью.

Страница GitHub Pages явно задаёт:

- `og:title`;
- `og:description`;
- `og:image`;
- `og:url`;
- Twitter Card-поля.

## Как хранится картинка

Исходный JPEG преобразован в Base64 и разделён на небольшие файлы:

```text
share/assets/card-1.0.4.b64.part01
...
share/assets/card-1.0.4.b64.part10
```

В версии 1.0.5 используется то же оформление карточки. Workflow собирает из этих частей новый публичный файл:

```text
kvas-zhizha-ai-agent-1.0.5.jpg
```

Workflow:

1. склеивает части в правильном порядке;
2. декодирует JPEG;
3. проверяет размер и сигнатуру JPEG;
4. проверяет Open Graph-поля;
5. проверяет JSON состояния и его версию;
6. публикует страницу.

## Как обновлять карточку дальше

Для новой версии:

1. При необходимости сделать новую картинку.
2. Преобразовать JPEG в Base64 и разделить на части.
3. Обновить версию и URL в `share/index.html`.
4. Обновить версию и имя выходного JPEG в `.github/workflows/pages.yml`.
5. Обновить `share/telegram-message.txt`.
6. Использовать новую версионную ссылку, например:

```text
https://bambuchastudent.github.io/kvas-ai-agent/v1.0.6/
```

Версионная ссылка помогает обойти старый кэш карточки в мессенджере.

## GitHub Pages

Публикацией занимается:

```text
.github/workflows/pages.yml
```

Если Pages ещё не включён:

```text
Settings → Pages → Build and deployment → Source → GitHub Actions
```

После этого workflow **Deploy Telegram share page** публикует страницу автоматически.
