# Как делиться проектом в Telegram

## Правильная ссылка

Для Telegram отправляй не обычную ссылку на репозиторий, а специальную страницу:

```text
https://bambuchastudent.github.io/kvas-ai-agent/v1.0.4/
```

У страницы зафиксированы:

- заголовок: **Квас Жижа для ИИ-агента**;
- изображение с бутылкой кваса и этим же заголовком;
- короткое описание проекта;
- кнопка «Поделиться в Telegram»;
- кнопка перехода в GitHub;
- ссылка на русскую инструкцию для ИИ-агента.

## Готовое сообщение

```text
Квас Жижа для ИИ-агента

Открытая база знаний про воспроизводимый домашний квас: простой рецепт в граммах, безопасность, визуальный контроль, журнал партий и инструкции для ИИ-агентов на русском, английском, испанском и немецком.

https://bambuchastudent.github.io/kvas-ai-agent/v1.0.4/
```

## Почему используется отдельная страница

GitHub сам формирует карточку для обычной ссылки на репозиторий. README не может надёжно задать Telegram свой заголовок и картинку.

Поэтому проект публикует маленькую страницу через GitHub Pages. В её HTML явно указаны:

- `og:title`;
- `og:description`;
- `og:image`;
- `og:url`;
- Twitter Card-поля.

Telegram получает карточку из этой страницы, а пользователь после открытия видит кнопки перехода и репоста.

## Как хранится картинка

Исходный JPEG преобразован в Base64 и разделён на небольшие файлы:

```text
share/assets/card-1.0.4.b64.part01
...
share/assets/card-1.0.4.b64.part10
```

Workflow:

1. склеивает части в правильном порядке;
2. декодирует JPEG;
3. проверяет размер файла;
4. проверяет начало и конец JPEG;
5. проверяет обязательные Open Graph-поля в HTML;
6. только после этого публикует страницу.

## Как обновлять карточку

Для новой версии:

1. Сделать новую картинку с нужным заголовком.
2. Преобразовать JPEG в Base64.
3. Разделить Base64 на последовательно названные части в `share/assets/`.
4. Обновить версию, размеры и URL картинки в `share/index.html`.
5. Обновить версию и имена файлов в `.github/workflows/pages.yml`.
6. Добавить новую версионную страницу, например:

```text
https://bambuchastudent.github.io/kvas-ai-agent/v1.0.5/
```

Версионная ссылка помогает не зависеть от старого кэша карточки в мессенджере.

## GitHub Pages

Публикацией занимается workflow:

```text
.github/workflows/pages.yml
```

Если Pages ещё не включён для репозитория, один раз открыть:

```text
Settings → Pages → Build and deployment → Source → GitHub Actions
```

После этого workflow **Deploy Telegram share page** публикует страницу автоматически при изменениях в `share/`.
