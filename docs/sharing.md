# Как поделиться проектом «Жижа»

Этот файл нужен, чтобы быстро объяснить другим людям, что это за проект и зачем он им.

## Ссылка

```text
https://github.com/bambuchastudent/kvas-ai-agent
```

Видимое имя проекта: **Жижа**.

Техническое имя репозитория пока остаётся `kvas-ai-agent`, чтобы старая ссылка не потерялась. Если репозиторий будет переименован на GitHub, старые ссылки обычно продолжают перенаправляться.

## Короткое сообщение

```text
Я собираю открытый проект «Жижа» — живую базу знаний про домашний квас и бытовую ферментацию. Там есть пошаговый рецепт, инструкции для ИИ-агентов, версии на русском/английском/испанском/немецком и чеклист безопасности. Можно пользоваться, спорить, проверять, предлагать правки и добавлять свой опыт: https://github.com/bambuchastudent/kvas-ai-agent
```

## Очень короткое сообщение

```text
«Жижа» — открытая база знаний про домашний квас: рецепты, безопасность, версии для ИИ-агентов и заметки сообщества. Можно пользоваться и улучшать: https://github.com/bambuchastudent/kvas-ai-agent
```

## Для людей, которые не любят GitHub

```text
Это не кодовый проект, а папка с понятными текстами: рецептами, инструкциями и чеклистами. GitHub здесь используется просто как место, где удобно хранить версии, правки и переводы.
```

## Как попросить человека помочь

```text
Посмотри, пожалуйста, рецепт и скажи, что бы ты поправил по своему опыту: пропорции, время, продукты, безопасность, перевод или понятность текста. Особенно полезны реальные проверки на кухне.
```

## Что можно предложить проекту

- проверенные пропорции;
- заметки по температуре и времени;
- варианты ингредиентов из разных стран;
- предупреждения по безопасности;
- переводы;
- фотографии упаковок ингредиентов без личных данных;
- идеи, как сделать инструкцию понятнее.

## Как объяснить идею «собор и базар»

```text
«Жижа» хочет быть одновременно аккуратной инструкцией и живым народным рецептом. Собор — это структура, безопасность, версии и переводы. Базар — это опыт людей, маленькие правки, споры, эксперименты и реальные кухни.
```
