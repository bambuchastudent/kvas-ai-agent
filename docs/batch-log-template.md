# Журнал партии кваса

Копируй этот шаблон для каждой новой партии. Цель — повторять удачные результаты и понимать, почему партия получилась лучше или хуже.

## Идентификатор партии

```text
Партия: KVAS-YYYY-MM-DD-01
Дата:
Автор:
Город/страна:
Версия протокола: 1.0.4
```

## Итог

```text
Партия удачная: да / нет
Повторить без изменений: да / нет
Зафиксировать как baseline: да / нет
Что изменить в следующей партии:
```

## Следующая гипотеза

Менять только один параметр за раз.

```text
В следующей партии меняю только:
Ожидаемый эффект:
```

Пример корректного сравнения:

```text
Партия 1: белый сахар 110 г.
Партия 2: всё то же, но панела 110 г.
Партия 3: всё то же, но мальтоза 110 г.
```
