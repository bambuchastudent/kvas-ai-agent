# Журнал партии кваса

Копируй этот шаблон для каждой новой партии. Цель — сделать квас воспроизводимым, а не каждый раз угадывать заново.

## Идентификатор партии

```text
Партия: KVAS-YYYY-MM-DD-01
Дата:
Автор:
Город/страна:
```
