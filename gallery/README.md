# Галерея успешных напитков

В галерею попадают только реальные удачные партии кваса. Чтобы предложить напиток, откройте Issue или Pull Request и приложите:

- фотографию готового напитка без личных данных;
- название партии;
- пропорции ингредиентов;
- температуру и время основного брожения;
- время догазирования и охлаждения;
- короткое описание вкуса и результата;
- имя или псевдоним автора, если его нужно показать.

## Формат записи

Изображение добавляется в `gallery/assets/`, а запись — в массив `drinks` файла `gallery/drinks.json`:

```json
{
  "title": "Ржаная Жижа №1",
  "description": "Хлебный аромат, умеренная кислинка и мягкая газация.",
  "author": "Имя или псевдоним",
  "image": "assets/rye-zhizha-01.jpg",
  "recipe_url": "https://github.com/bambuchastudent/kvas-ai-agent/..."
}
```

Не добавляйте лица, адреса, номера телефонов и другие персональные данные без явного согласия.
